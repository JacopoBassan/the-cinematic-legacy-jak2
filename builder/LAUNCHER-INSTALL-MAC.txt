Jak II: The Cinematic Legacy for OpenGOAL
Apple Silicon macOS candidate.
By @jacopobassan
https://jacopobassan.me

Supported discs: PAL SCES-51608 and USA SCUS-97265 v2.01.

1. Install vanilla Jak II with OpenGOAL tooling v0.3.9.
2. Close the game. Open Features > Mods > Add from File in OpenGOAL Launcher.
   Select the matching Mac .tar.gz archive.
3. Wait for setup, then press Play.

No separate Python installation or terminal is needed.
Setup builds the models from your installed game files. Mods have separate saves.
Vanilla saves stay in place and are not copied automatically.

Allow space for the mod installation and temporary conversion.
Logs remain in OpenGOAL-Cinematic-Builds beside the OpenGOAL installation.
Successful builds remove temporary assets. Failed builds retain diagnostics.
